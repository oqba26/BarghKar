# طرح پیاده‌سازی اپلیکیشن «برق‌کار» (BarghKar)

این برنامه به عنوان یک دستیار جامع برای برق‌کاران طراحی می‌شود که شامل محاسبات فنی، مراجع استاندارد و مدیریت متریال پروژه‌ها خواهد بود.

## ساختار پیشنهادی
ما از معماری **MVVM** و **Jetpack Compose** استفاده خواهیم کرد. همچنین برای ناوبری (Navigation) از یک سیستم Bottom Navigation یا Drawer استفاده می‌کنیم تا دسترسی به بخش‌های مختلف سریع باشد.

## مراحل پیشنهادی تغییرات

### ۱. زیرساخت و ناوبری (Core & Navigation)
*   راه‌اندازی کتابخانه‌های مورد نیاز (Navigation Compose, Material 3 Icons).
*   ایجاد ساختار پوشه‌بندی برای لایه‌های Data, Domain و UI.
*   پیاده‌سازی صفحه اصلی با منوی دسترسی به بخش‌های مختلف.

### ۲. بخش محاسبات (Calculators)
*   **[NEW]** `OhmLawScreen`: رابط کاربری برای محاسبه ولتاژ، جریان و مقاومت.
*   **[NEW]** `VoltageDropScreen`: محاسبه افت ولتاژ بر اساس پارامترهای استاندارد.

### ۳. بخش مراجع (References)
*   **[NEW]** `ColorCodeScreen`: راهنمای تصویری استانداردهای رنگ‌بندی سیم.
*   **[NEW]** `SymbolLibraryScreen`: لیستی از نمادهای الکتریکی با توضیحات.

### ۴. مدیریت پروژه و متریال (Project Management)
*   راه‌اندازی **Room Database** برای ذخیره لیست خرید پروژه‌ها.
*   **[NEW]** `ProjectListScreen`: مشاهده و مدیریت پروژه‌ها.
*   **[NEW]** `MaterialListScreen`: افزودن و ویرایش اقلام مورد نیاز برای هر پروژه.

### ۵. ابزارهای کاربردی (Utility Tools)
*   **[NEW]** `UnitConverterScreen`: تبدیل واحدهای AWG، میلی‌متر مربع و غیره.
*   **[NEW]** قابلیت کنترل چراغ قوه (Flashlight Controller).

## برنامه تأیید (Verification Plan)

### تست‌های خودکار
*   Unit Test برای فرمول‌های ریاضی در بخش محاسبات (اطمینان از صحت خروجی قانون اهم و افت ولتاژ).
*   تست صحت عملکرد دیتابیس Room برای ذخیره پروژه‌ها.
